Course Introduction

大數據分析：POA 輿情系統實作

這是一門整合型課程：自然語言處理、網頁前後端技術、大型語言模型應用與深度學習、爬蟲技術與 Python 資料分析。 我們以真實的新聞輿情平台為主軸，帶你從資料分析走到 Agentic AI 系統落地。

  • Public Opinion Analysis
  • Python+Pandas
  • Django+Database
  • LLM
  • Agentic Workflow + RAG

About This Course / 課程簡介

This course focuses on public opinion analysis as a practical integration of natural language processing, web development, large language models, and Python data analysis. With a real news and public opinion platform as the main example, you will learn how to move from data analysis to an Agentic AI system.

本課程以新聞輿情平台為主軸，整合 Python 資料分析、NLP、網頁前後端與大型語言模型應用，帶你從資料分析走向可落地的 Agentic AI 系統。

Syllabus / 授課主題

  • Python 基礎 / Python Introduction：Python資料分析、NumPy、Pandas。
  • 自然語言處理 / NLP：斷詞、詞性分析、命名實體分析、詞頻統計、全文檢索。
  • 語言模型AI / LLM：新聞情緒分析、Agent AI、RAG語意搜尋。
  • 網頁技術 / Website Design：爬蟲、Django、前端互動與後端整合、Ajax與REST API。

深度學習主題

大型語言模型與輿情分析的應用

  • 1. 使用大型語言模型進行情緒分析
  • 2. 製作新聞摘要
  • 3. 大型語言模型的代理人（Agent）應用
  • 4. RAG 的語意新聞內容查詢

Why Choose This Course? / 為什麼要選修這門課？

這是一門整合型課程，你會把大學與研究所學過的 IT 技術整合起來，完成一個真實可運行的系統。 You will not only learn concepts, but also complete a deployable project.

  • 你會學到目前業界重視的技能：Python、Django、JavaScript、NLP、LLM、RAG、Agentic Workflow。
  • Learning by doing：從做中學、從範例中學、逐步拆解練習。
  • 課程成果可轉化為履歷與作品集，提升前後端、資料分析與 AI 工程競爭力。

Scoring / Grading 評分規定

  • 1. (20%) Class exercises and attendance / 課堂操作與出席上課
  • 2. (15%) homework / 作業
  • 3. (30%) Midterm project / 期中專案：Public Opinion Analysis Website (Basic)
  • 4. (35%) Term project / 期末專案：Public Opinion Analysis Website (Complete)
  • 個人+AI一起完成專案
