API Introduction

REST API in Modern Web Development

REST API 是目前網頁開發與系統整合的主流方式。它可以把資料分析能力獨立成服務，讓網站前端、Python 程式、其他應用程式，甚至後台系統都能以同一套介面呼叫。

  • RESTful Style
  • JSON Response
  • Cross-Platform Integration
  • Backend Service Architecture

Web Development Trend / 開發趨勢

現代網站不再只把邏輯寫在前端頁面，而是把功能切成 API 服務。前端只負責顯示與互動，後端提供乾淨的資料介面，這樣更容易維護、擴充與跨平台共用。

在這個專案裡，我們把熱門關鍵詞、人物分析、關聯度分析、新聞段落擷取、情緒分析等功能都做成可直接呼叫的 API。

Our APIs / 本專案 API

  • 熱門關鍵詞（Top Keywords）
  • 人物分析（Top Persons）
  • 關聯度分析（Correlation）
  • 新聞段落搜尋（Paragraph Retrieval）
  • 情緒分析（Sentiment Analysis）
  • 其他更多分析功能都可以逐步封裝成 API

API Response / 回傳格式

我們建議所有 API 都回傳 JSON，讓前端、Python、React 或其他系統都能輕鬆處理。

{ "status": "ok", "query": "政治", "data": [ { "keyword": "選舉", "score": 98 }, { "keyword": "政策", "score": 89 } ] }

Why REST API?

REST API 的好處是簡單、標準、跨平台，而且很適合拆分成前後端分離的系統架構。你可以讓使用者直接呼叫，也可以讓自己的網站後台或 AI Agent 呼叫。

Use Cases / 使用情境

這些 API 可以直接提供給一般使用者查詢，也可以供你自己的網站後台、管理系統、AI 應用或資料儀表板整合使用。

How to Call / 呼叫方式

以下每個範例都同時示範 GET（查詢）與 POST（送出條件/建立分析任務）。

1. Python

import requests # GET get_url = "https://example.com/api/top-keywords" get_res = requests.get(get_url, params={"query": "政治"}) print(get_res.json()) # POST post_url = "https://example.com/api/correlation" payload = {"keyword_a": "台積電", "keyword_b": "AI"} post_res = requests.post(post_url, json=payload) print(post_res.json())

2. jQuery

$.ajax({ url: '/api/top-keywords', method: 'GET', data: { query: '政治' }, success: function (res) { console.log(res); } }); $.ajax({ url: '/api/correlation', method: 'POST', contentType: 'application/json', data: JSON.stringify({ keyword_a: '台積電', keyword_b: 'AI' }), success: function (res) { console.log(res); } });

3. JavaScript

fetch('/api/top-keywords?query=政治') .then(res => res.json()) .then(data => { console.log(data); }); fetch('/api/correlation', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ keyword_a: '台積電', keyword_b: 'AI' }) }) .then(res => res.json()) .then(data => { console.log(data); });

4. ReactJS

// GET useEffect(() => { fetch('/api/top-keywords?query=政治') .then(res => res.json()) .then(setData); }, []);
// POST const createCorrelation = async () => { const res = await fetch('/api/correlation', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ keyword_a: '台積電', keyword_b: 'AI' }) }); const data = await res.json(); console.log(data); };

Typical Flow / 典型流程

Client / Frontend / Python App / React App -> REST API -> Django View -> Analysis Function -> JSON Response
  • 先送出 query、category、date range 等參數。
  • 後端執行分析邏輯，回傳標準 JSON。
  • 前端或其他應用程式再把結果渲染成圖表、列表或報表。
