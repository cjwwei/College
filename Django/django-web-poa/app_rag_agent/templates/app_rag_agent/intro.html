Agentic RAG 金融諮詢 APP 介紹

這是一個結合財經新聞檢索、語意理解與智能代理人決策能力的互動式金融智能助手。

1. 這個 APP 的用途是什麼？

本 APP 主要用途是幫助使用者快速查詢台灣半導體、IC 設計、電子產業等財經新聞資訊，並提供： 具體新聞引用、分類過濾、目標價估算、以及安全範圍內的智能回覆。

2. 整體流程說明

  1. 使用者輸入問題：例如「查聯發科最新發表的晶片特色」或「整理 IC 設計類別新聞連結」。
  2. 系統判斷問題類型：模型會決定是要使用語意檢索、分類 SQL 查詢，或是數學計算工具。
  3. 調用工具或檢索資料：如果是新聞查詢，會透過 RAG 將語意查詢轉為向量並檢索新聞片段；如果是分類清單，則直接做 SQL 濾搜；如果是估值計算，會使用內建計算工具。
  4. 生成回答：模型根據檢索結果與工具輸出，整合成清楚、有來源標註的答案回傳給使用者。
  5. 對話歷史保存：每次提問與回答會被存進 session，讓下一輪對話可以延續上下文。

3. 什麼是 RAG？

RAG 全名是 Retrieval-Augmented Generation（檢索增強式生成）。 它的核心概念是：先從資料庫檢索出相關內容，再把這些真實資料交給語言模型生成回答，避免模型單憑記憶或猜測產生幻覺。

在本 APP 中，RAG 的作用是：

  • 把使用者問題轉為語意向量
  • 在財經新聞資料庫中找到最相關的新聞片段
  • 用檢索到的新聞片段當作依據來回答問題

4. Agent 代理人背後在做什麼？

這裡的 Agent 是指「能夠主動決策或呼叫外部工具的語言模型」，而不是只純粹用規則回答的聊天機器人。

本 APP 的 Agent 背後運作流程： 它會根據問題判斷是否需要進行以下動作：

  • 呼叫 news search 工具進行語意檢索
  • 呼叫 category list 工具進行 SQL 篩選
  • 呼叫 估值計算 工具做精確數學運算

Agent 的優勢是它可以依據不同問題，自主選擇最適合的工具，並整合結果輸出一致的回答。

5. 為什麼要把 RAG 與 Agent 結合？

RAG 和 Agent 各有強項，合在一起可以補足彼此的不足：

  • RAG 提供事實依據：避免模型直接憑空生成答案，降低誤導風險。
  • Agent 提供工具調度：根據問題自動選擇檢索、過濾或計算工具。
  • 實現更高品質回覆：同時兼顧資料正確性、金融專業性與使用者需求。
