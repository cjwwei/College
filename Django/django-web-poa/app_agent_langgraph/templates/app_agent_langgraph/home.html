📌 關於此 App (第三階段：Custom LangGraph 狀態圖工作流)

本系統是一個結合「Django Session 記憶機制」與「LangGraph 自定義狀態圖」的輿情智能助理。
運作架構特色：採用 LangGraph 的 StateGraph 架構，您的指令會在自定義的多層 Node 中流轉。系統會根據 Gemini 3.1 Flash Lite 的分析，在「思考節點」→「工具節點」→「判斷節點」等不同的計算點間完成推理迴圈。每個節點都擁有完全的狀態掌控，能夠精準地呼叫後端封裝的資料庫查詢工具（如熱門關鍵字、知名人物頻率、關鍵字關聯分析等），最終由 LLM 將原始數據轉譯成易懂的回答。您可以在終端機觀察完整的 Node 跳轉過程。
