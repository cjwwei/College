📌 關於此 App (第二階段：LangChain 代理人)

本系統是一個結合「Django Session 記憶機制」與「LangChain Tool-Calling Agent 架構」的輿情智能助理。
運作架構特色：當您輸入指令時，LangChain 會結合您的歷史對話上下文理解題意，自動判定並呼叫後端所封裝的多個資料庫查詢工具（Tools：如熱門關鍵字、知名人物頻率、關鍵字關聯分析等），獲取原始數據後，再使用 LLM 轉譯成人類好懂的答案回答您。
